# Package index

## Data sets

To showcase the functionality of the Morefi package, the two data sets
from Aguirre-Villaseñor et al. (2025) are included.

- [`Botete`](https://macrurido.github.io/Morefi/reference/Botete.md) :
  Biometric data of the bullseye puffer
- [`Botete_land`](https://macrurido.github.io/Morefi/reference/Botete_land.md)
  : Records of the bullseye puffer catch landed.
