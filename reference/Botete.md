# Biometric data of the bullseye puffer

Biometric data of the bullseye puffer \*Sphoeroides annulatus\*
collected from the Sinaloa coast of the Mexican Pacific Ocean.

## Usage

``` r
Botete
```

## Format

\## \`Botete\` A data frame with 1397 obs. of 7 variables:

- LT:

  Total length (cm)

- LS:

  Standard length (cm)

- LB:

  Body trunk length (cm)

- WT:

  Total weight (g)

- WB:

  Body trunk weight (g)

- Wfi:

  Fillet weight (g)

- Fleet:

  Fleet code 1: artisanal fishing and two trawling methods

## Source

\<https://github.com/Macrurido/Morefi.git\>

## Details

The variable 'Fleet' classifies types of fishing: artisanal (fresh
market) as 1 and trawling (frozen-thawed market) as 2.

For further information, please refer to the article by
Aguirre-Villaseñor et al. (submitted).
